A catastrophe exposure analysis depicts the frequency and geographic locations of natural disasters across a region in order to accurately predict future financial loss. This project was built using publicly available FEMA disaster declaration data covering all federally declared disasters across 57 US states and territories from 2000 to 2026. I used SQL to aggregate disaster frequency and incident diversity by state, calculate annual disaster rates, and analyze how the national disaster mix has shifted over time. The findings were organized in a risk scoring model that ranks all 57 states on combined disaster frequency and diversity, assigning each to one of four risk tiers. Results were then visualized in a Tableau dashboard featuring a geographic heat map of disaster concentration, along with charts showing disaster counts separated by year and type.
